⚙ Cours en Temps Réel — Paramètres API

Clé API personnelle Alpha Vantage (gratuite sur alphavantage.co). Utilisée uniquement dans ton navigateur, stockée dans le State exporté en JSON. Quota gratuit ≈ 25 requêtes/jour, 5/minute.

Sans clé API (ou si le quota est atteint / la requête échoue), mets simplement à jour le champ "Cours actuel" manuellement sur chaque ligne — l'application fonctionne intégralement sans API.
